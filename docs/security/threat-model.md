# 위협 모델

챗봇 가드(파트 A)가 중심이다. 파트 안내는 [README.md](README.md).

## 챗봇 (STRIDE)

| 위협 | 예시 | 막는 곳 | 상태 |
|---|---|---|---|
| 스푸핑 (S) | 다른 사용자인 척 "user_id 3의 일정 알려줘" | 도구는 JWT의 user_id만 사용 | 챗봇 미구현 |
| 변조 (T) | 공지·닉네임에 숨긴 지시문(간접 인젝션) | 도구 결과를 구분자로 감싸 데이터로만 취급 | 챗봇 미구현 |
| 부인 (R) | 차단된 요청의 기록이 없음 | `record_security_event` | 이벤트 기록 있음 |
| 정보 노출 (I) | 시스템 프롬프트 추출, 응답 속 이메일·좌표 | 출력 가드 | 가드 틀만 있음 |
| 서비스 거부 (D) | 긴 입력, 반복 호출로 토큰 소모 | 입력 길이 상한, 챗봇 20/5분, 세션 토큰 상한 | 길이 상한만 |
| 권한 상승 (E) | "매치 취소해줘"로 쓰기 동작 유도 | 도구 전부 읽기 전용, 출력 가드 | 챗봇 미구현 |

## 범위 축소로 받아들인 한계
- 토큰은 access JWT 하나(24시간), 브라우저 저장소에 둔다. XSS가 나면 탈취될 수 있고 서버가 만료 전에 무효화할 수 없다.
- 레이트리밋은 서버 메모리라 재시작하면 초기화된다.
- `GET /metrics`는 인증이 없다(로컬·스테이징 전용).

## 의도적 취약점 (학습용, `main`에 남겨 둠)
- **비밀번호 원문 저장**: `core/security.py`의 `hash_password`/`verify_password`. 교체할 때는 이 두 함수만 바꾼다.
