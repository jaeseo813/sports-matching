# 005. 정상 답이 출력 가드에 막힘: 버튼을 글자로 씀, 분류 오탐

- 날짜: 2026-11-25 / 대상: `services/chatbot.py`, `services/chat_guard.py`
- 상태: **조치 완료** / 종류: 과잉 차단(가용성)
- 심각도: **낮음** — 새는 것은 없다. 대신 가장 흔한 질문에서 답을 못 받는다.

## 1. 버튼 도구 호출을 글자로 쓴다
"이번 주말 풋살 매치 찾아줘"를 40번 보내면 6번이 `OUTPUT_BLOCKED`. 답에 `<button view_match 576>`, `suggest_action` 같은 글자가 섞여
`PROMPT_LEAK`·`HTML` 규칙에 걸렸다. 출력 LLM 분류를 붙이기 전부터 있던 규칙이다.

**원인**: 차례별로 기록해 보니 LLM이 버튼을 하나씩 띄우다 도구 차례(`MAX_TOOL_ROUNDS` 3)를 다 쓰고, 도구를 막은 마지막 차례(`tool_choice="none"`)에서 남은 버튼을 글자로 썼다.
**조치**: 차례를 5로 늘린 첫 수정은 40번에서 0번이었지만, 이후 80번에서 2번 다시 막혔다(1번은 결과 5개에 버튼을 하나씩 띄워 또 모자람, 1번은 `auto` 차례에서 글자로 씀).
→ `MAX_TOOL_ROUNDS = 2 + MAX_RESULTS`(7), 시스템 프롬프트에 "도구 호출이나 태그를 글자로 쓰지 않는다". 60번에서 0번. 가드는 느슨하게 하지 않았다.

## 2. 출력 분류가 안전한 답을 막는다
실제 답 501개 중 6개가 막혔다. 수치와 조치는 [chat-guard-eval.md](../chat-guard-eval.md) v3.1.

## 3. 앱에 없는 기능을 안내한다
"숫자 점수는 프로필 화면에서 확인"(정상 경로), "매치 화면에서 주최자에게 채팅"(입력 가드 끔). 앱에 둘 다 없다.
**조치**: 시스템 프롬프트에 없는 기능을 명시. 같은 질문 18개씩 비교해 없는 기능 안내 1 → 0, 주최자 문의에 "채팅·연락 기능이 없다"고 답한 것 0/6 → 6/6.
"프로필 화면" 답은 수정 전에도 다시 나오지 않아 그 한 건의 효과는 재지 못했다.

## 남은 것
- LLM 답은 매번 달라 0/60이 0%를 뜻하지 않는다. 글자로 쓴 도구 호출은 다시 나와도 규칙이 막는다.
- 버튼을 4개 이상 띄우려 하면 화면에는 3개(`MAX_ACTIONS`)만 나가지만 LLM은 모른다.
